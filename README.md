
# 🔬 DermAI — AI-Based Skin Cancer Detection

A deep learning web app for skin lesion classification using the **HAM10000 dataset**.

## Models
- Ensemble (DenseNet201 + InceptionV3)
- DenseNet201 Retrained & Finetuned
- InceptionV3 Retrained & Finetuned
- InceptionResNetV2 Finetuned
- VGG16 Finetuned
- Baseline CNN

## Classes
Actinic Keratosis · Basal Cell Carcinoma · Benign Keratosis · Dermatofibroma · Melanoma · Melanocytic Nevi · Vascular Lesion
